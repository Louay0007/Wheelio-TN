# Wheelio TN

Multi-agency car rental marketplace frontend for Tunisia.

## Stack

- Next.js 16
- React 19
- Tailwind CSS 4
- Framer Motion
- pnpm

## Local development

```bash
cd wheelio-frontend
pnpm install
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000).

## Production build

```bash
cd wheelio-frontend
pnpm build
pnpm start
```

## Deploy on Vercel

1. Import this GitHub repository in Vercel.
2. Set **Root Directory** to `wheelio-frontend`.
3. Framework preset: **Next.js**.
4. Install command: `pnpm install`
5. Build command: `pnpm build`
6. Output: default Next.js output.

No environment variables are required for the current landing page.
